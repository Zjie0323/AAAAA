A股实时看板 · 使用说明
=======================

收到此看板后，请按以下三步使用（约 2 分钟）。

【文件清单】
本压缩包内应有以下 3 个文件（放在同一目录下，不要拆分）：

  server.py      后端代理服务（提供行情接口、规避浏览器 CORS）
  index.html     前端看板页面
  start.bat      一键启动脚本（Windows）

────────────────────────────────────────────────────────
第一步：安装 Python（如未装）
────────────────────────────────────────────────────────

  下载地址：https://www.python.org/downloads/

  安装时务必勾选最下方的 "Add python.exe to PATH"
  （不勾选的话 start.bat 找不到 Python，会报错）

  要求版本：Python 3.7 或更高

────────────────────────────────────────────────────────
第二步：启动服务
────────────────────────────────────────────────────────

  双击  start.bat

  正常输出示例：
    [OK] Service already running at http://localhost:8000
         （首次启动不会出现，重复启动时才会）

    或

    Using Python: C:\...\python.exe
    Starting A-stock realtime board at http://localhost:8000
    (Press Ctrl+C to stop)

  ★ 关键：此窗口必须保持开着。关闭窗口 = 停止服务。

────────────────────────────────────────────────────────
第三步：打开浏览器
────────────────────────────────────────────────────────

  浏览器（Chrome / Edge / Firefox）访问：

    http://localhost:8000

  即可看到看板。

  看板包含：
    涨停个股 / 跌停个股（带连板、封单、封板时间）
    板块资金流（行业 / 概念）
    我的持仓（搜索代码或名称添加，盈亏实时计算）
    智能推荐（按《交易逻辑》筛选的低位连板候选）
    分时图（点击任一股票行查看）

────────────────────────────────────────────────────────
常见问题
────────────────────────────────────────────────────────

  Q：双击 start.bat 后窗口一闪而过？
  A：Python 没装或没加 PATH，请回第一步重装。

  Q：start.bat 提示"port already in use"或"残留监听"？
  A：会自动清理，等几秒就好。

  Q：浏览器打开后报 "Failed to fetch"？
  A：你可能直接双击了 index.html。必须先双击 start.bat
     启动服务，然后浏览器访问 http://localhost:8000
     （不要从文件管理器双击 index.html！）。

  Q：数据空白 / 一直加载？
  A：检查网络（服务需能访问东方财富/腾讯行情接口）；
     或在交易时段（9:30-11:30 / 13:00-15:00）打开，
     休市时段会显示上一交易日收盘快照。

  Q：端口 8000 已被其他程序占用？
  A：编辑 start.bat，把第一处 set PORT=8000 改成
     其他端口（如 8080），然后从 http://localhost:8080 访问。

  Q：怎么停止服务？
  A：在 start.bat 窗口按 Ctrl+C，或直接关闭窗口。

────────────────────────────────────────────────────────
★ 重要：避免从 Microsoft Store 安装 Python
────────────────────────────────────────────────────────

  Windows 上搜"Python"会同时出现两个来源：
    - python.org 标准安装包（推荐）
    - Microsoft Store 的 Python（不推荐，常出怪问题）

  如果只装了 Store 版，Windows 会注册一个"应用执行别名"：
    C:\Users\<你>\AppData\Local\Microsoft\WindowsApps\python.exe

  这个文件存在，但不是一个真正的解释器，server.py 用它启动
  会**静默失败**（无报错但端口连不上）。

  解决办法：去 https://www.python.org/downloads/ 下载标准安装包
  安装，**安装时务必勾选 "Add python.exe to PATH"**。装好后
  start.bat 会自动用真正的 python.exe。

────────────────────────────────────────────────────────
首次启动若遇到问题
────────────────────────────────────────────────────────

  看 start.bat 同目录下生成的  _start.log  文件，
  它记录了 Python 查找、端口探测、服务启动的每一步详情，
  可发给开发者协助排障。
